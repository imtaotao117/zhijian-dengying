# 《指尖灯影》—— 手势交互数字皮影戏

> 第十四届全国大学生数字媒体科技作品及创意竞赛 · 命题五「民族文化·创新表达」参赛作品

《指尖灯影》是一款以中国皮影戏为题材的浏览器交互作品。用户可通过摄像头手势、鼠标、触控或键盘操控影人，体验经典剧目、自由操影、皮影拼装、关节造型、定格动画和非遗知识。

作品的体验闭环为：**看戏 → 操影 → 造影 → 学艺**。

## 一、核心模块

| 模块 | 内容 |
| --- | --- |
| 经典剧目 | 《三打白骨精》《大闹天宫》《哪吒闹海》三出引导式剧目；关键节点以伸一指、点击或空格“拍板”推进。默认开启评审演示模式，每出约60–90秒，也可切换完整模式。 |
| 自由操影 | 行走、跳跃、亮相、出招、盘坐、换景；支持双手操控双角色。 |
| 皮影工坊 | 10个头茬、7个身段、9件兵器、10套敷彩，以及10个经典角色一键整装；作品可保存到浏览器并导入舞台。 |
| 关节工坊 | 关节拖拽、双骨IK、隔空操骨、6关亮相挑战、定格动画与PNG导出。 |
| 非遗课堂 | 历史时间轴、8个地域流派示意点、制作八道工序、课堂内容搜索、DeepSeek 皮影问答和官方资料来源。 |

首次打开首页会显示三步新手引导，介绍剧目拍板、手势操影与鼠标/键盘备用操作；在引导中主动点击“检测并开启摄像头”才会请求摄像头权限。之后可从首页重新打开引导。

| 动作 | 摄像头手势 | 鼠标 / 触控 | 键盘 |

摄像头界面会实时显示手部骨架与当前识别结果。鼠标、触控和键盘始终作为演示备用方案。

## 三、运行

### 本机答辩模式（推荐）

1. 安装 Node.js 18 或更高版本。
2. 双击 `启动服务器.bat`。
3. 浏览器打开 `http://localhost:8080`。

服务器默认只监听 `127.0.0.1`，不会向公共网络开放。

### 局域网触控演示

双击 `启动局域网演示.bat`，再让手机或平板访问电脑的局域网IP与8080端口。

注意：

- 只应在可信局域网中使用。
- 手机/平板通过普通 `http://电脑IP:8080` 访问时可使用触控模式。
- 非 `localhost` 的普通HTTP通常不属于安全上下文，不能保证移动设备摄像头手势可用；远程手势演示应部署到HTTPS。

### 自检

- `diagnostics/model-test.html`：检查本地MediaPipe与GPU/CPU初始化。
- `diagnostics/cam-test.html`：检查安全上下文、浏览器摄像头API、设备枚举和取流。

### 智能问答配置

课堂资料搜索始终可用，不需要网络或 API 密钥。页面会先检测本地问答服务的配置状态；点击“问 DeepSeek”才会调用远端 API，并将输入的问题及少量相关课堂文字发往 DeepSeek。回答下方可查看并跳转到本次提供给模型参考的课堂条目，但这不等于模型逐条引用；它是知识问答，不是实时联网搜索，回答仍应结合页面底部的官方来源核对。

本机项目目录中可以建立 `.env.local` 文件，内容为：

```text
DEEPSEEK_API_KEY=你的DeepSeek密钥
```

也可在启动服务器的终端设置同名环境变量。密钥只由 `server.js` 读取，不放进网页。修改密钥后需重启服务器。“私用版”压缩包包含已配置的 `.env.local`，解压后无需再次填写密钥；请勿将它公开分享。“公开版”压缩包不含密钥，课堂资料搜索可直接使用，DeepSeek 问答会显示未配置，需由部署者在服务端另行配置密钥。不要把真实密钥提交到 Git 或公开压缩包。

需要 Node.js 18 或更高版本及可访问 DeepSeek API 的网络。服务端使用 `deepseek-flash` 非思考模式；每个客户端每分钟最多提问 5 次，单次问题最多 200 字。模型名称和接口以 [DeepSeek 官方文档](https://api-docs.deepseek.com/api/create-chat-completion/)为准。

## 四、技术架构

```text
摄像头帧
  → MediaPipe HandLandmarker（21关键点，最多双手）
  → 手势分类与跨帧消抖
  → 统一输入事件层（手势 / 指针 / 键盘）
  → 皮影骨骼、IK与状态动画
  → Canvas 2D舞台、粒子和灯影效果
  → WebAudio实时锣鼓与提示反馈
```

- 手势模型、WASM和中文字体均随项目本地提供。
- GPU不可用时自动尝试CPU模式。
- 评审演示模式采用0.4倍时间轴，完整模式保留原叙事节奏。
- 剧目进度以“幕次+百分比”呈现，避免用几十个内部节拍干扰观众。
- 非遗课堂与服务端共用 `js/classroom-data.js`；本地搜索不发出网络请求，智能问答由本地服务端代发，网页无法读取 API 密钥。

## 六、内容、许可与AI披露

- 皮影角色与部件的原创情况应以团队保存的源文件、草图、版本记录和成员签字声明为准。
- MediaPipe与字体不是“CC素材”；准确版本、来源和许可证见 `THIRD_PARTY_NOTICES.md`。
- 历史沿革中的早期起源与海外传播存在不同观点，页面采用审慎措辞；国家级和联合国名录信息见 `docs/非遗资料来源.md`。
- 本作品已加入 DeepSeek 实时问答。参赛前必须由团队据实填写并签字确认 `AI_USE_DISCLOSURE.md`，说明运行时生成式 AI 的用途，并核查赛事相关要求。

## 八、建议测试基线

至少覆盖：3种设备或摄像头；明亮、普通、偏暗3种光照；30–70cm距离；单手与双手；Chrome与Edge稳定版；1280×720桌面与390×844移动端触控。

记录识别成功率、误触次数、首个有效动作时间、平均响应延迟、帧率和任务完成率，模板见 `docs/测试记录模板.md`。

代码与资源一致性可执行：`node scripts/release-check.js`。该脚本不替代真实摄像头、移动端和用户测试。

生成发布包时，使用 PowerShell 7 分别运行 `pwsh -File scripts/package-release.ps1 -Mode private`（含密钥，仅个人保存）或 `pwsh -File scripts/package-release.ps1 -Mode public`（不含密钥）。脚本会使用不同文件名，不覆盖已有压缩包，并检查公开版不含 `.env.local`。

另外可运行 `node scripts/api-contract-test.js`，在不联网、不读取真实密钥的情况下检查问答接口状态与参考资料字段。
